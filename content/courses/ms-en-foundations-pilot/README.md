# Malay-interface English foundations pilot

This is an **internal draft content package** for engineering and editorial
workflow validation. It is deliberately not a published course and must not
be seeded into a production release.

Before this package can be promoted, content ownership must replace every
pending review and rights value with real approval references, expand the
course to 20–40 measurable objectives, and create a separate approved release
manifest. The validator will reject a relabelled draft.

Run the deterministic contract gate from `apps/mobile-rn`:

```text
npm run validate:content
```

The client may load only server-side `published` course releases. This JSON is
not bundled as a learner-visible offline fallback.
