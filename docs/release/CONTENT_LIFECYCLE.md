# Spark Lingo Content Lifecycle Architecture (CONTENT_LIFECYCLE.md)

This specification defines the content architecture, data sources, mapping tables, AI integration, and validation workflow for Spark Lingo.

## 1. Content Sources

Spark Lingo utilizes three distinct content layers:

1. **Sentence & Vocabulary Layer (Tatoeba)**:
   - Community-translated sentence pairs for 400+ languages extracted via `fetch_tatoeba.py`.
   - Supplies raw vocabulary items and authentic contextual sentences.

2. **Native Audio Layer (Mozilla Common Voice)**:
   - Open native pronunciation dataset matched to Tatoeba sentence IDs via `process_common_voice.py`.
   - Delivers real human audio recordings instead of synthetic TTS.

3. **Structured Curriculum & Assessment Layer (CEFR & Exam Bodies)**:
   - Grammar explanations, CEFR "Can-do" progression (A1-C2), and exam-specific rubrics (HSK 1-9, JLPT N5-N1, DELE, DELF, Goethe, IELTS/TOEFL).
   - Generated by Sparky AI pipeline grounded in CEFR Companion Volume descriptors and validated via native-speaker review (`00h_content_validation.md`).

## 2. Curriculum Mapping Hierarchy

```
Language (e.g., "es", "fr", "zh")
  └─ CEFR / Exam Level (e.g., "A1", "A2", "B1", "B2", "HSK1", "JLPT_N5")
       └─ Unit (e.g., "es-dele-a1-unit-01")
            └─ Lesson (Vocabulary, Grammar, AI Tutor Conversation, Mock Exam)
                 └─ Flashcards (SM-2 State) / Question Items
```

### Supabase Core Tables:
- `units`: Unit metadata, level mapping, `source_attribution`, `is_reviewed`, `publish_state`.
- `lessons`: Lesson titles, descriptions, unit relationships.
- `flashcards`: SM-2 review parameters (`interval`, `ease_factor`, `repetitions`).
- `exam_definitions`: Framework mapping rules (CEFR, HSK, JLPT).
- `exam_level_mappings`: Unit progression gates to target levels.

## 3. Storage & Operational Architecture

- **Source of Truth**: PostgreSQL in Supabase (`units`, `lessons`, `flashcards`).
- **Audio Assets**: Supabase Storage bucket (`/audio/{lang}/{sound_id}.mp3`).
- **Offline Fallback**: `assets/syllabus_master.json` bundles verified starter curriculum for offline resilience.

## 4. AI Grounding & Human-in-the-Loop Gate

- **Sparky Grounding**: During AI tutor sessions, the system injects the current unit's vocabulary and grammar bounds into the prompt context to keep practice focused.
- **Content Review Gate**: All AI-drafted curriculum sits in `publish_state = 'draft'` until marked `is_reviewed = true` by a native speaker. Unreviewed draft content is never served to production clients.
