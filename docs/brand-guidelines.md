### Accessibility (measured, not estimated)

- Never use color alone to convey state (ux rule #37): pair with icon/text.

Fallback chain: Segoe UI, Roboto, Helvetica Neue, Arial, sans-serif.

1.5–1.75 for body; #76 darker text on light backgrounds; #77 clear
heading/body size+weight separation.

## 4. Component Language (GetWidget, themed via SparkGF)

- GFCard: radius 20, elevation 3, indigo border — language grid, exam,
  practice surfaces.
- GFButton primary: #4F46E5 solid, w800 label, large.
- GFBadge: pill, indigo tint; green variant = "Popular"/verified.
- GFProgressBar: 12pt line, green fill, indigo-tinted track.

---

## 5. Voice & Content Rules

- Never fabricate scores, exam formats, or readiness percentages —
  verified official sources only (exam module honesty contract).
- AI content carries the Sparky AI identity; errors are specific and
  actionable (never minified type names).
- Consent asked once per session, persisted; privacy-first language.
